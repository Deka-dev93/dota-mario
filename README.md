# Dota Mario

Платформер в духе Марио с героями в стиле Доты: **Pudge, Invoker, Meepo, Earthshaker**.
Написан на Python и pygame. Вся графика и звук рисуются кодом.

## Запуск

- Готовая игра: `dist/DotaMario.exe` (Python не нужен).
- Из исходников: `Запустить игру.bat` или `py game.py` (нужен `py -m pip install pygame-ce`).

## Управление

| Действие | Клавиши |
|---|---|
| Бег | A / D или стрелки |
| Прыжок | W, стрелка вверх или пробел (чем дольше держите, тем выше) |
| Способности | J или X, K или C |
| Пауза | P |
| Музыка вкл/выкл | M |
| Окно / полный экран | F11 или Alt+Enter |
| Свечение (эффект) вкл/выкл | Q |
| Качество графики (Обычная / Высокая / Максимальная) | G |
| Назад / пауза | Esc (короткое нажатие) |
| **Выход из игры** | **удерживать Esc 2 секунды** |

Окно можно растягивать мышью: картинка плавно масштабируется с сохранением пропорций (по бокам появляются чёрные полосы). Выбранный режим (окно или полный экран) и размер окна запоминаются.

### Чёткость картинки

Игра рисуется сразу в высоком разрешении (до 1920×1080), а не растягивается из маленького кадра, поэтому и текст, и герои остаются чёткими. Уровни качества: «Обычная» (960×540), «Высокая» (1440×810), «Максимальная» (1920×1080). Если компьютер не справляется и игра идёт рывками, она сама снизит качество; клавиша G переключает вручную.

## Игра

- **Карта мира.** Дорога между шестью уровнями, как в Марио. Развилка: уровни 3 и 4 можно проходить в любом порядке, на 5-й пускает любой из них. Последний уровень — битва с Рошаном.
- **Aghanim's Shard** работает как гриб в Марио: выпадает из блока «?», бегает по уровню. Подобрали — герой получает усиление способностей и перезарядка уменьшается на 30%. Удар врага забирает шард, а не здоровье.
- **Монеты.** Монета даёт 10 золота, а 100 монет дают +1 жизнь. Золото тратится в магазине (клавиша B на карте): скорость, здоровье, перезарядка, шард на старте уровня, жизни.
- **Жизни.** Три на старте. Закончились — игра окончена, но пройденные уровни сохраняются.
- Прогресс сохраняется в `%APPDATA%/DotaMario/save.json`. Клавиша N в меню сбрасывает его.

## Музыка

Музыка в папке `music/` сочинена кодом (`make_music.py`) — оригинальные треки в стиле замедленного фонка с реверберацией:
`level` — уровни, `map` — карта и меню, `boss` — Рошан.

Чтобы поставить свой трек, положите файл `music/level.mp3` (или `.ogg`, `.wav`) рядом с игрой. Игра предпочтёт его. Так же можно заменить `map` и `boss`.

## Фан-проект

Dota 2 и её персонажи принадлежат Valve. В игре нет файлов из Dota 2, все рисунки нарисованы кодом заново.
